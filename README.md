# HOI4 모드 관리자 (공유용)

Hearts of Iron IV 용 **네이티브 DLL·스크립트 모드**를 골라서 켜고 끄고, 언제든 게임 폴더를 원본 상태로 되돌리는 프로그램입니다.
이 저장소에는 **안정 판정을 받은 모드만** 들어 있고, 프로그램이 이 저장소에서 모드를 직접 내려받아 관리합니다.

- 필요 환경: Windows 10/11 (.NET Framework 4.8 — 윈도우에 기본 포함, 별도 설치 불필요)
- 필요한 것: `HOI4ModManager.exe` 파일 하나 (이 저장소 맨 위에 있습니다)

## 설치

1. `HOI4ModManager.exe` 를 내려받아 아무 폴더에 둡니다(바탕화면·다운로드 폴더 모두 가능).
2. 실행하면 **모드를 보관할 폴더**를 묻습니다. 기본값은 `문서\HOI4 Mod Manager` 입니다. 비어 있는 폴더를 권장하며, 그 안에 `mods`, `loader`, `data` 폴더가 만들어집니다.
3. 저장소(GitHub)에서 모드가 자동으로 내려받아집니다. 게임 폴더는 Steam 에서 자동으로 찾고, 못 찾으면 `hoi4.exe` 가 있는 폴더를 직접 고르면 됩니다.
4. 목록에서 사용할 모드의 **스위치를 눌러 켭니다.** 모드 이름을 누르면 설명이 열립니다. (게임이 실행 중이면 스위치가 잠깁니다.)

## 업데이트

| 방법 | 설명 |
| :--- | :--- |
| 자동 확인 | 프로그램을 켜 두면 **하루에 한 번** 저장소에 변경이 있는지 확인합니다. 끄려면 `하루 한 번 자동 확인` 체크를 해제하세요. 확인만 하고, 내려받기는 직접 눌러야 합니다. |
| 수동 확인 | `업데이트 확인` 버튼. 변경이 있으면 새 모드·바뀐 모드를 보여 주고, 확인하면 **바뀐 파일만** 내려받아 설치합니다. |
| 안전장치 | 내려받은 모든 파일은 저장소의 `manifest.json` 해시와 대조합니다. 하나라도 맞지 않으면 아무것도 바꾸지 않습니다. |
| 켜 둔 모드 | 업데이트로 바뀐 모드가 켜져 있으면 게임 폴더에도 바로 적용합니다(게임 실행 중이면 종료 후 `다시 적용`). |
| 프로그램 자체 | 새 버전이 있으면 교체하고 다시 시작할지 물어봅니다. |

내가 조정한 모드 설정 파일(예: `cas_ace.txt`)은 업데이트해도 **내 설정이 그대로 유지**됩니다.

## 주요 기능

- **모드 켜기/끄기**: 스위치를 누르는 즉시 게임 폴더에 설치/제거됩니다. 실패하면 이전 상태로 자동 복귀합니다.
- **DLL 모드 여러 개 동시 사용**: 로더가 자동으로 설정됩니다.
- **전체 초기화 (원본 복구)**: 모든 모드를 끄고 덮어썼던 원본 파일을 복원하며, 관리 프로그램 밖에서 설치된 모드 파일까지 정리합니다. `version.dll` 은 게임 원본에 없는 파일이므로 백업 없이 삭제합니다.
- **폴더 검사**: 게임 폴더에서 관리 프로그램 밖에서 설치된 모드 파일·로그를 찾아 정리합니다.
- **게임 실행**: Steam 으로 HOI4 를 실행합니다.

## 문제가 생기면

- **백신이 경고합니다**: 이 프로그램은 서명되지 않은 개인 제작 프로그램이고, 모드는 게임에 끼어드는 `version.dll`(프록시 DLL)이라 일부 백신(Windows Defender 포함)이 오탐할 수 있습니다. 믿을 수 있다고 판단될 때만 예외로 등록하세요. 배포 파일의 해시(SHA-256)는 `manifest.json` 에서 확인할 수 있습니다.
- **업데이트 확인이 실패합니다**: 인터넷 연결을 확인하세요. 자동 확인은 실패하면 조용히 넘어가고 몇 시간 뒤 다시 시도합니다.
- **설치 폴더를 바꾸고 싶습니다**: 모드를 모두 끈 뒤 프로그램을 종료하고, `%APPDATA%\HOI4ModManager\install_folder.txt` 를 지우고 다시 실행하면 폴더를 다시 묻습니다(새 폴더에서 처음부터 내려받습니다).
- 작업 기록은 프로그램 아래쪽 창과 설치 폴더의 `data\manager.log` 에 남습니다.

## 포함된 모드

프로그램의 `모드 리스트` 버튼에서 모든 모드의 설명을 볼 수 있습니다.
