# HOI4 모드 관리자 (공유용)

**한국어** | [English](README.en.md)

Hearts of Iron IV 용 **네이티브 DLL·스크립트 모드**를 골라서 켜고 끄고, 언제든 게임 폴더를 원본 상태로 되돌리는 프로그램입니다.
이 저장소에는 **개발자가 안정 판정을 한 모드만** 들어 있고, 프로그램이 이 저장소에서 모드를 직접 내려받아 관리합니다.

- 필요 환경: Windows 10/11 (.NET Framework 4.8 — 윈도우에 기본 포함, 별도 설치 불필요)
- 필요한 것: `HOI4ModManager.exe` 파일 하나 (이 저장소 맨 위에 있습니다)

## 설치

1. `HOI4ModManager.exe` 를 내려받아 아무 폴더에 둡니다(바탕화면·다운로드 폴더 모두 가능).
2. 실행하면 **모드를 보관할 폴더**를 묻습니다. 기본값은 `문서\HOI4 Mod Manager` 입니다. 비어 있는 폴더를 권장하며, 그 안에 `mods`, `loader`, `data` 폴더가 만들어집니다.
3. 저장소(GitHub)에서 모드가 자동으로 내려받아집니다. 게임 폴더는 Steam 에서 자동으로 찾고, 못 찾으면 `hoi4.exe` 가 있는 폴더를 직접 고르면 됩니다.
4. 목록에서 사용할 모드의 **스위치를 눌러 켭니다.** 모드 이름을 누르면 설명이 열립니다. (게임이 실행 중이면 스위치가 잠깁니다.)

## 업데이트

| 방법 | 설명 |
| :--- | :--- |
| 자동 확인 | 프로그램을 켜 두면 **하루에 한 번** 저장소에 변경이 있는지 확인합니다. 끄려면 `하루 한 번 자동 확인` 체크를 해제하세요. 확인만 하고, 내려받기는 직접 눌러야 합니다. |
| 수동 확인 | `업데이트 확인` 버튼. 변경이 있으면 새 모드·바뀐 모드를 보여 주고, 확인하면 **바뀐 파일만** 내려받아 설치합니다. |
| 안전장치 | 내려받은 모든 파일은 저장소의 `manifest.json` 해시와 대조합니다. 하나라도 맞지 않으면 아무것도 바꾸지 않습니다. |
| 켜 둔 모드 | 업데이트를 설치하면 **켜져 있던 모드를 기억해 두었다가, 모든 모드를 껐다가 기억한 모드를 다시 켜서** 바뀐 내용을 게임 폴더에 자동으로 반영합니다. 게임이 실행 중이면 게임을 끄는 순간(또는 프로그램을 다시 켤 때) 이어서 합니다. |
| 프로그램 자체 | 새 버전이 있으면 교체하고 다시 시작할지 물어봅니다. |

내가 조정한 모드 설정 파일(예: `cas_ace.txt`)은 업데이트해도 **내 설정이 그대로 유지**됩니다.

## 주요 기능

- **모드 켜기/끄기**: 스위치를 누르는 즉시 게임 폴더에 설치/제거됩니다. 실패하면 이전 상태로 자동 복귀합니다.
- **모두 켜기 / 모두 끄기**: 모든 모드를 한꺼번에 켜거나 끕니다(켤 때는 서로 함께 쓸 수 없는 모드를 뺍니다).
- **설정 저장 / 설정 불러오기**: 지금 켜져 있는 모드 조합에 이름을 붙여 저장해 두었다가, 나중에 불러와 그대로 복구합니다(예: 멀티플레이 때는 `전체 초기화` 로 원본 상태로 돌려놓고, 싱글플레이로 돌아올 때 `설정 불러오기` 한 번으로 복구). 팝업 창에서 저장할 이름을 입력하고, 저장해 둔 설정을 고르거나 삭제할 수 있습니다. 저장한 설정은 `data\settings.json` 에 들어 있습니다.
- **DLL 모드 여러 개 동시 사용**: 로더가 자동으로 설정됩니다. 게임 폴더에는 로더 `version.dll` 만 두고, 나머지는 게임 폴더의 `mods` 폴더에 **`mod`**(모드 DLL·설정 파일)와 **`log`**(로그)로 나누어 보관합니다.
- **로그 보관 기한 1주일**: 각 모드가 로그를 `mods\log` 에 직접 쓰고(모든 줄이 날짜·시각으로 시작), 관리 프로그램은 7일이 지난 줄을 로그 앞부분에서 자동으로 잘라냅니다. 게임이 켜져 있는 동안에는 자르지 않습니다.
- **전체 초기화 (원본 복구)**: 모든 모드를 끄고 덮어썼던 원본 파일을 복원하며, 관리 프로그램 밖에서 설치된 모드 파일까지 정리합니다. `version.dll` 은 게임 원본에 없는 파일이므로 백업 없이 삭제합니다.
- **폴더 검사**: 게임 폴더에서 관리 프로그램 밖에서 설치된 모드 파일·로그를 찾아 정리합니다.
- **게임 실행**: Steam 으로 HOI4 를 실행합니다.
- **한국어 / English**: 처음 실행하면 윈도우 표시 언어를 따라 언어가 정해집니다(한국어 윈도우는 한국어, 그 밖에는 영어). 화면 오른쪽 위의 언어 선택으로 언제든 바꿀 수 있고, **모드가 게임 안에서 표시하는 글(결정·툴팁·창 등)도 프로그램 언어를 따라갑니다.** 게임을 켜 둔 상태에서 바꾸면 게임을 끈 뒤 `다시 적용`을 눌러야 게임 안의 언어가 바뀝니다. (모드가 남기는 로그 파일은 번역되지 않습니다.)

## 문제가 생기면

- **백신이 경고합니다**: 이 프로그램은 서명되지 않은 개인 제작 프로그램이고, 모드는 게임에 끼어드는 `version.dll`(프록시 DLL)이라 일부 백신(Windows Defender 포함)이 오탐할 수 있습니다. 믿을 수 있다고 판단될 때만 예외로 등록하세요. 배포 파일의 해시(SHA-256)는 `manifest.json` 에서 확인할 수 있습니다.
- **업데이트 확인이 실패합니다**: 인터넷 연결을 확인하세요. 자동 확인은 실패하면 조용히 넘어가고 몇 시간 뒤 다시 시도합니다.
- **설치 폴더를 바꾸고 싶습니다**: 모드를 모두 끈 뒤 프로그램을 종료하고, `%APPDATA%\HOI4ModManager\install_folder.txt` 를 지우고 다시 실행하면 폴더를 다시 묻습니다(새 폴더에서 처음부터 내려받습니다).
- 작업 기록은 프로그램 아래쪽 창과 설치 폴더의 `data\manager.log` 에 남습니다.

## 주의 사항

- **싱글 플레이 전용**: 본 프로그램의 모드는 창작마당용 모드가 가지는 한계를 극복하기 위해 게임 작동 자체를 건드리는 방식이기 때문에 멀티플레이에서 정상적인 작동을 보장하지 않습니다. 싱글 플레이에서만 사용해주세요.

## 포함된 모드

프로그램의 `모드 리스트` 버튼에서 모든 모드의 자세한 설명을 볼 수 있습니다. 아래는 이 저장소가 제공하는 모드의 제목과 요약입니다.

| 모드 | 요약 |
| :--- | :--- |
| **에이스 조종사 자동 배치** | 빈 비행단에 대기 중인 에이스를 자동으로 배치하고, 에이스가 전사하거나 새로 진급하면 즉시 교체·투입합니다. |
| **수동 정밀 전선 드래그** | 국경을 우클릭 드래그해 전선을 그릴 때 주 경계나 강을 지나며 전선이 반대편으로 뒤집히는 현상을 막고, 드래그한 범위에만 정확히 전선을 만듭니다. |
| **전선 분리/증발 방지** | 평화 중인 제3국이 적 영토를 점령하는 등 전선이 바뀔 때 전선 명령이 평화국 쪽으로 갈라지거나 옮겨 가는 것과, 전선이 쪼개져 내가 그은 전선이 통째로 사라지는 것을 막습니다. |
| **비행단 에이스 생성 확장** | 피해를 주는 모든 비행단 작전(근접항공지원·전략폭격·병참 타격 등)이 해전과 같은 에이스 판정을 출격마다 받게 합니다. |
| **병참 타격 아군 피해 방지** | 병참 타격의 번짐 피해가 자신·동맹·중립 나라의 인프라와 철도에 떨어지지 않게 합니다. |
| **자동 무역** | 자원 부족분을 무역으로 자동 수입하고, 과잉 수입·막힌 항로·비효율 거래를 정리합니다. 결정 탭의 설정 창에서 자원별 목표와 우선순위·금지 조건을 조절합니다. |
| **자동 훈장 부여** | 사단 지휘관에게 정치력으로 훈장(야전 표창)을 자동으로 부여합니다. 결정 탭의 설정 창에서 정치력 하한선, 사단 편제 이름별·장군/원수별 우선순위와 금지, 훈장 우선순위(훈장별 능력 표시), 부대 순서를 조절합니다. |
| **종속국 합병 건설 정지 수정** | 종속국의 주에 짓던 건물이 그 종속국을 합병한 뒤 진도 없이 공장만 묶이는 버그를 막습니다. 합병·주 소유 변경 직후 짝을 잃은 건설 줄의 연결을 끊어 일반 건설로 이어서 짓게 합니다(진행·공장 유지). |
| **국경 분쟁 무전투 패배 방지** | 국경 분쟁(중국 군벌 등)이 시작하자마자 사단이 없다고 판정돼 전투 없이 끝나는 것을 막습니다. 길 찾기 검사에서 사단이 모두 탈락해도 한 번 더 골라 전쟁을 시작하고, 병력이 도착할 14일을 줍니다. |
| **국경 분쟁 전문 지휘관** | 국경 분쟁이 시작될 때 게임이 아무 장군·원수나 원래 군에서 빼 가는 것을 막습니다. 설정 창에서 지정한 전문 지휘관 1명이 모든 국경 분쟁을 맡고, 전문 지휘관이 가진 사단을 먼저 투입합니다. |
| **평시 세력 단일 전선** | 평시에도 같은 세력(진영) 나라들의 국경을 하나의 전선으로 묶어 한 번에 사단을 배치할 수 있게 합니다. 세력의 일부 나라와만 전쟁을 시작해도 전선이 쪼개지지 않습니다. |
| **정당 지지도 툴팁 출처 표시** | 정당 지지도 툴팁에서 이름 없이 숫자만 이어 붙던 보장(독립보장) 드리프트 줄을 이름과 함께 한 줄씩 보여 줍니다. 텍스트만 바꿉니다. |
| **철도 레벨 단계별 건설** | 철도를 한 번에 2레벨 이상 올릴 때 시작점부터 한 구간씩 목표 레벨까지 짓는 대신 경로 전체를 1레벨씩 올려, 건설 중에도 보급 효과 향상 효과를 얻을 수 있게 합니다. |
| **핵심주 저항·순응 즉시 정리** | 점령주를 핵심주로 만들면 다음 날 저항도·순응도를 없애, F6(저항)·F7(순응) 맵 모드에서 핵심주가 곧장 빠지게 합니다. |
